# SACC-SoC后端方向题解

南京邮电大学(NJUPT)“流量的密码”互联网平台场景编程挑战后端方向题解仓库。

## 开发环境

- Java 17+
- Visual Studio Code
- Extension Pack for Java

## 项目说明

本项目使用 Java 完成比赛题目，涉及变量、条件判断、循环、函数、递归、类与对象、字符串处理和 I/O 等内容。

每道题的题解代码和相关说明放在对应目录中。代码经过本地测试，具体运行方式以各题目录中的说明为准。

## 目录结构

```text
.
├── README.md
├── ai-prompts.md
├── 01-题目名称/
│   └── src/
└── 02-题目名称/
    └── src/
```

## 运行方式

使用 VS Code 打开仓库，在 Java 项目中运行对应题目的主类即可。

如果题目需要额外配置或依赖，请以对应目录下的 `README.md` 为准。

## AI 使用说明

如开发过程中使用 AI 辅助，将在 `ai-prompts.md` 中记录相关提示词、使用过程和修改说明。
